## vim をインストールしよう

Ubuntu/Debianの場合
```
apt update -y
apt install -y vim 
``` 

RedHat系の場合
```
dnf install -y vim 
``` 

## vim の操作方法をしろう

基本操作: vimtutor コマンドを利用してtutorialをしよう。

```
$ vimtutor
```
